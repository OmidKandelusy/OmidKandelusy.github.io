Digital Fourier Signal Processing

Frequency domain analysis is a powerful engineering framework which enables tractable and straightforward mechanisms to investigate and predict behavior of dynamic systems, especially the communication systems. In this context, there are several ways to transform a dynamic system from the common temporal domain into a mathematically convenient domain: Fourier, Laplace, Z, wavelet, Hilbert, to name a few. Each of these transform spaces have their own limitations such a convergence criterion that makes them attractive for certain problem setups. The Fourier space is particularly exciting as it can be used for the steady state sinusoid regimes which essentially encompasses the wide variety of the dynamic systems we are dealing with everyday from wireless communication systems to mechanical systems. However, there are some nuances involved in using computers to do the Fourier space analysis which I would like write a few paragraphs here about it.
